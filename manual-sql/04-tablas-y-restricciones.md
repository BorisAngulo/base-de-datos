# 4. Tablas y restricciones (DDL)

Una tabla es la estructura: columnas + reglas. Las reglas viven en el
**esquema**, no en el programa Java.

## 4.1. Crear

**PostgreSQL**

```sql
CREATE TABLE producto (
    id      INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre  TEXT           NOT NULL,
    precio  NUMERIC(10, 2) NOT NULL,
    stock   INTEGER        NOT NULL,
    CONSTRAINT chk_stock_no_negativo CHECK (stock >= 0),
    CONSTRAINT chk_precio_positivo   CHECK (precio > 0)
);
```

**MySQL**

```sql
CREATE TABLE producto (
    id      INT AUTO_INCREMENT PRIMARY KEY,
    nombre  VARCHAR(120)   NOT NULL,
    precio  DECIMAL(10, 2) NOT NULL,
    stock   INT            NOT NULL,
    CONSTRAINT chk_stock_no_negativo CHECK (stock >= 0),
    CONSTRAINT chk_precio_positivo   CHECK (precio > 0)
) ENGINE = InnoDB;
```

`ENGINE = InnoDB` es obligatorio si quieres transacciones y claves foráneas
(MyISAM no las cumple). En MySQL 8+ InnoDB ya es el motor por defecto.

## 4.2. Restricciones

| Restricción | Qué garantiza |
|-------------|---------------|
| `PRIMARY KEY` | Única y no nula. Identifica la fila. |
| `NOT NULL` | La columna siempre tiene valor. |
| `UNIQUE` | No se repite (sí admite varios `NULL` en PostgreSQL). |
| `DEFAULT expr` | Valor si el `INSERT` no la menciona. |
| `CHECK (condición)` | Regla de negocio (`stock >= 0`). |
| `FOREIGN KEY` | [Capítulo 8](08-claves-foraneas.md). |

La PK se puede declarar en la columna (`id INTEGER PRIMARY KEY`) o al pie:

```sql
CONSTRAINT producto_pkey PRIMARY KEY (id)
```

Útil cuando la clave es compuesta: `PRIMARY KEY (venta_id, producto_id)`.

## 4.3. Inspeccionar

```text
-- PostgreSQL
\d producto

-- MySQL
DESCRIBE producto;
SHOW CREATE TABLE producto;
```

```sql
-- Ambos (information_schema)
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_name = 'producto'
ORDER BY ordinal_position;
```

## 4.4. Alterar

```sql
ALTER TABLE producto ADD COLUMN activo BOOLEAN NOT NULL DEFAULT TRUE;
ALTER TABLE producto DROP COLUMN activo;

ALTER TABLE producto ADD CONSTRAINT uq_nombre UNIQUE (nombre);

-- PostgreSQL
ALTER TABLE producto ALTER COLUMN nombre TYPE VARCHAR(120);
ALTER TABLE producto ALTER COLUMN stock SET DEFAULT 0;

-- MySQL
ALTER TABLE producto MODIFY nombre VARCHAR(160) NOT NULL;
ALTER TABLE producto ALTER COLUMN stock SET DEFAULT 0;
```

Renombrar:

```sql
-- PostgreSQL
ALTER TABLE producto RENAME TO articulo;
ALTER TABLE articulo RENAME COLUMN nombre TO descripcion;

-- MySQL
RENAME TABLE producto TO articulo;
ALTER TABLE articulo RENAME COLUMN nombre TO descripcion;
```

## 4.5. Borrar

```sql
DROP TABLE producto;                 -- error si no existe
DROP TABLE IF EXISTS producto;       -- silencioso
DROP TABLE IF EXISTS venta, producto, categoria, cliente;
```

El orden importa si hay FK: primero las tablas que **referencian**,
después las referenciadas. O `DROP TABLE ... CASCADE` (PostgreSQL) /
revisar `FOREIGN_KEY_CHECKS` (MySQL, con cuidado).

## 4.6. Script del catálogo del curso

Ejecuta esto (ajusta tipos autonuméricos según el motor) antes de seguir.
Versión PostgreSQL:

```sql
DROP TABLE IF EXISTS venta;
DROP TABLE IF EXISTS producto;
DROP TABLE IF EXISTS cliente;
DROP TABLE IF EXISTS categoria;

CREATE TABLE categoria (
    id     INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre TEXT NOT NULL UNIQUE
);

CREATE TABLE cliente (
    id     INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre TEXT NOT NULL
);

CREATE TABLE producto (
    id           INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre       TEXT           NOT NULL,
    precio       NUMERIC(10, 2) NOT NULL,
    stock        INTEGER        NOT NULL DEFAULT 0,
    categoria_id INTEGER        REFERENCES categoria (id),
    CONSTRAINT chk_stock_no_negativo CHECK (stock >= 0),
    CONSTRAINT chk_precio_positivo   CHECK (precio > 0)
);

CREATE TABLE venta (
    id          INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    producto_id INTEGER NOT NULL REFERENCES producto (id),
    cliente_id  INTEGER NOT NULL REFERENCES cliente (id),
    cantidad    INTEGER NOT NULL CHECK (cantidad > 0),
    fecha       DATE    NOT NULL DEFAULT CURRENT_DATE
);
```

En MySQL cambia `INTEGER GENERATED ... IDENTITY` por `INT AUTO_INCREMENT`,
`TEXT` por `VARCHAR(120)`, `NUMERIC` por `DECIMAL`, y añade `ENGINE=InnoDB`.
